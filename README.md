# スクロールアルゴリズム比較アプリ (Scroll Algorithm Comparator)

大量のデータを描画する際における、一般的なスクロール処理と「仮想スクロール（バーチャルスクロール）」のパフォーマンス・仕組みの違いを体感・検証するためのデスクトップアプリケーションです。

##  概要
本アプリは、1万件のテキストデータをリスト表示するにあたり、以下の2つのアプローチを切り替えて挙動を比較できます。

1. **通常スクロール (Naive Approach)**
   - 全データ（1万件）のUI部品を最初からすべて生成して配置します。データ量に比例してメモリを消費し、初期描画時にフリーズ（オーバーヘッド）が発生する現象を体感できます。
2. **仮想スクロール (Virtual Scroll)**
   - 画面の表示領域内にあるデータ（15件分）だけを動的に計算して描画します。データ量がどれだけ増えても、常に一瞬（数ミリ秒）で処理が完了するアルゴリズムの効率性を確認できます。

## 動作環境
- Python 3.x
- 標準ライブラリ `tkinter`（追加インストールの必要はありません）

## 📊 学べるアルゴリズムのポイント
- **描画コストの最適化:** 画面外の要素を「描画しない」ことによるパフォーマンスの向上。
- **データとビューの分離:** スクロール位置（インデックス）から、今どのデータを描画すべきかを算出する計算ロジック。

# ゲームスクロール・アルゴリズム体験アプリ (Game Scroll Algorithm Simulator)


2Dアクションゲームやシューティングゲームの開発で頻繁に使われる、主要な「カメラ追従（スクロール）アルゴリズム」を視覚的に比較・テストできるミニシミュレーターです。

## 🎮 概要
赤い四角形（プレイヤー）をキーボードで操作し、リアルタイムに変化するカメラワークと背景の挙動を体感できます。以下の3つのアルゴリズムを切り替え可能です。

1. **プレイヤー追従 (Player-Centered)**
   - プレイヤーが常に画面の「中央」に位置するようにカメラ座標を更新する、最もオーソドックスなアルゴリズム。
2. **スクロールロック / デッドゾーン (Camera Deadzone)**
   - 画面中央に一定の猶予エリア（黄色い点線）を設け、プレイヤーがその枠を押し出そうとした時だけカメラが追従する探索型ゲーム向けのアルゴリズム。
3. **視差効果 (Parallax Scroll)**
   - 遠景（星）と中景（ビル）の移動速度（スクロール係数）を変えることで、平面の2D画面に劇的な奥行きと立体感を与えるシューティング・アクションの定番アルゴリズム。

## 🕹 操作方法
- **左矢印キー (`←`)**: 左へ移動
- **右矢印キー (`→`)**: 右へ移動
- **ラジオボタン（上部）**: アルゴリズムのリアルタイム切り替え

## 🧮 コア・ロジック（座標変換公式）
このアプリのゲームスクロールは、以下のゲーム開発における基本数式に基づいて実装されています。
$$\text{画面上の描画位置} = \text{ゲーム世界での絶対座標} - \text{カメラの座標}$$
